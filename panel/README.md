# Panel — the dollhouse UI

The custom Flutter application for the wall touchscreen: 2.5D isometric stacked floors,
neumorphic styling, tap-to-expand rooms, device state via Home Assistant's WebSocket API.

**Status: not started.** The Flutter project is created here only after the spike
(`../spike/`) passes its pass/fail checklist (`../docs/research/flutter-cage-spike.md` §4).
Reusable pieces of the spike app (multi-touch visualizer as a hidden debug screen, the
runner fullscreen patch, cursor hiding) migrate here at that point.
