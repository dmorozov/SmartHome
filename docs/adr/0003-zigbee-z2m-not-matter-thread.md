# Zigbee via Zigbee2MQTT for new devices, not Matter-over-Thread

New outlets/switches (~10–25 devices) are Zigbee, run through Zigbee2MQTT with an SMLIGHT SLZB-06 Ethernet coordinator; first-choice products are Inovelli Blue Series 2-1 in-wall switches and ThirdReality Gen2 metering plugs, with Athom ESPHome plugs for special cases. Matter-over-Thread — the "obvious" 2026 choice — was deliberately rejected for the mainline purchase: border-router and ecosystem-fragmentation pain conflicts with the project's reliability-first goal, while Zigbee+Z2M is fully local, self-meshing (every mains device is a repeater), and publishes devices as plain MQTT topics any client can consume, keeping the device layer independent of the Hub decision. Revisit Matter/Thread in a year; HA's matter.js server keeps that door open. Citations: `docs/research/hub-and-device-integrations.md` §4.
